# Nota de domínio — eixo real do negócio

> Arquivo de referência compartilhado, não é uma skill. Consultado a partir de outras skills
> deste diretório via link `[[_nota-dominio-eixo-real]]`.

Os exemplos usados nas skills deste projeto frequentemente giram em torno de assembleia,
votação e convocação porque são casos ricos em regra de negócio e risco jurídico — mas
**nenhum deles é o caso central ou exclusivo do sistema**.

O eixo real do negócio do Simpleto é **Administradora → Condomínio**: uma administradora
gerencia a carteira de vários condomínios, cada um com sua própria convenção/regimento. O
mesmo raciocínio, técnica ou regra aplicada a assembleia deve ser aplicada igualmente a outras
áreas do domínio — cobrança/financeiro, portaria, manutenção, reservas de área comum, entre
outras — sem tratar assembleia como prioridade implícita sobre elas.

Skills que citam esta nota devem manter, junto à referência, apenas a frase específica de como
esse princípio se aplica ao escopo daquela skill (ex.: quais indicadores, quais cenários de
teste, qual fronteira de módulo) — o parágrafo genérico acima não precisa ser recopiado.
